启动本机服务

在项目目录运行下面的命令，将路径替换为你的知识库目录。使用期间请保持终端打开。

node src/cli.mjs pages --library "/path/to/library"
首次安装与自定义端口

从 项目源码安装，准备好 Node.js 和 uv，然后在项目目录运行：

npm ci --ignore-scripts --legacy-peer-deps
uv sync --locked

如需更换端口，在启动命令末尾加上 --port 43123。编译 LaTeX 还需本机安装 latexmk 和 TeX 引擎。

GitHub Pages 只打开你指定的本机地址。阅读、批注与写作无需外部 API。
