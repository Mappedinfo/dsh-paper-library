**v0.2.0 已发布** · [Release](https://github.com/Mappedinfo/dsh-paper-library/releases/tag/v0.2.0) · [变更记录](https://github.com/Mappedinfo/dsh-paper-library/blob/main/CHANGELOG.md)

首帖之后插件又完成了 35 个提交，这里同步一下当前状态（仍然是非官方、社区维护、源码安装，尚未发布到 npm）。

### 阅读与批注

- **两种阅读模式（新增「选文后」切换）**：默认「勾选后提问」保持原流程 —— 拖选文字后写下问题或评注；新增「自动着色」—— 拖选即按当前颜色直接写成自然批注、不弹对话框，符合“先勾画、再阅读/提问”的习惯。模式、颜色与着色类型随阅读布局持久化，刷新后保留。
- **取色器与渲染颜色一致**：选区高亮此前是固定蓝/黄、批注回看闪示固定青色，与取色器无关；现在选区跟随所选颜色，闪示使用该批注自身的 PDF 颜色，颜色与模式经单一写入队列持久化（旧实现并发读改写会撞修订号并弹出保存重试条）。
- **精确选文**：隐形文字层此前与栅格文字不对齐（实测偏宽 18–34 px，词尾空格还压到下一个词上），拖选会命中相邻词、按词框裁剪又会丢掉浏览器已高亮的文字。现在每个词按 `scaleX` 精确贴合自己的词框，词间与行尾补上空格命中区；取文改为按选区切片、绝不丢弃已选中的字，预览完整显示多行选文。
- **换行拼接**：跨行选择不再凭空多一个空格（中文 PDF 一行常被抽取成一个“词”，此前每处换行都会多一个空格）；拉丁词同行保留空格，换行处不加分隔符，`measure-` + `ment` 仍是 `measure-ment`。
- **多条批注的 AI 回复各归其位**：此前一次为多条批注请求反馈，会把整段回答写在**每一条**批注下；现在模型按批注逐条回复，每条只写回自己的批注（PDF 原生 `/IRT`），未回答的批注会被标出而不是拿别人的答案填充；模型若仍返回合并答案则只保存一条并提示。

### 阅读项目与文献画板

- **阅读项目**：目录数据库新增 `projects` / `project_papers`（多对多）与归档表，一篇文献可同时属于多个项目。文献库顶部新增项目栏，可新建／编辑／归档，选中项目后列表只显示其成员并与搜索、排序、分页组合；画板也能关联项目。关联只增删边，移出项目不删除、不归档文献。
- **文献画板**：库 web 界面新增「画板」视图。SVG 自由画布支持平移缩放、文本/便签/矩形/椭圆/菱形节点、拖拽与改尺寸、连线（直线/折线/箭头/虚线、可插拐点）、多选、撤销重做；把文献拖上画布即成为绑定 `paper.id` 的节点，双击回到阅读器；勾选多篇可一键生成思维导图。
- **确定性排版与可读源文件**：分层树（lr/tb/rl/bt）、放射思维导图、分层图 DAG 三种自动排版；内容与样式可落到可读的 `board.json` / `board.style.json`，可生成、编辑、校验。
- **AI 可读写画板**：新增 `library_board` 工具，模型新增/修改的节点与连线标记为待评审，只有读者能接受 AI 改动。
- **独立侧栏入口**：同一个插件注册两个右栏标签类型 —— 「文献库」与「画板」，开始页面会列出两张入口卡片，可与文献库标签并排。

### 研究难点挖掘（P1–P4，可选）

- **P1 候选扫描（无模型）**：显式选择 1–50 篇，按小节边界做触发词/句式扫描，输出带真实页码与命中规则的候选段落；零模型调用、零网络。
- **P2 单篇受限抽取（模型）**：候选冻结为不可变来源，经隔离子代理产出难点记录（`gap`/`question` + 来源状态 + 逐字证据），保存为待核对草稿；引用校验失败不落盘、重复请求不重放。
- **P3 跨篇主题聚合（确定性优先）**：归一化标签聚合成语料级主题，给出覆盖篇数、年份分布、来源状态计数与代表引用；相似标签只给待审合并建议，接受/否决/合并均需人工复核。
- **P4 复核、对照与评审包**：结构检查按稳定代码报告缺证据/单篇/仅推断等问题；可与自有清单（粘贴文本或本地 `.md/.txt/.json/.csv/.bib`，记录来源与日期）做确定性覆盖对照并列出缺口；导出 `challenges.csv` / `.md` / `.bib` 与人工评审包。

### 范围没有变化的部分

- 仍无全库扫描、无后台 OCR、无向量／全文检索；扫描件与图像不计入结论。
- AI 生成内容一律标记待审阅，不编造作者、日期或 DOI；难点与主题一律从「待核对」起步。
- 容量验证仍是约 2,000 条记录 / 1,000 个小型合成 PDF；未验证真实大库、WPS 保存往返与提供商输出质量。
- 原创代码 MIT；默认 PyMuPDF、citeproc 运行时涉及 AGPL，CSL 资源为 CC BY-SA，可选的 Zotero translation-server 为 AGPL-3.0（由使用方单独运行）。

### 验证

当前通过 **485 项 JavaScript 与 220 项 Python 测试**，以及真实 Chromium 流程与原生 DSH 集成回执：阅读器 24 流程、选文精度 8 项、批注模式 7 项、AI 反馈 4 项、研究难点浏览器 10 项与原生宿主 7 项、阅读项目 9 项、画板 28 项。全部使用合成文档，未发起真实提供商请求；范围与复现方式见 [docs/validation.md](https://github.com/Mappedinfo/dsh-paper-library/blob/main/docs/validation.md)。

安装方式与首帖一致（源码注册到目标 profile，重启 DSH 后从右侧面板打开）。欢迎继续反馈导入失败的文件类型、批注兼容性，以及长时间阅读与整库整理时的表现。
