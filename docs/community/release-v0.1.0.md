首帖之后插件完成了多轮更新，这里同步一下当前状态（仍然是非官方、社区维护、源码安装，尚未发布到 npm）。

### 阅读与批注

- **阅读区与批注栏可自由缩放**：中间分隔条可拖动无级调整侧栏宽度（160–720 px，方向键可微调），PDF 随之自动重新适配。
- **PDF 任意缩放**：默认全宽自适应，可用 −／＋ 或直接输入 25–400% 的百分比，放大后横向滚动，渲染密度随缩放提高以免文字发虚；宽度与缩放保存在主机，刷新或换浏览器后恢复。
- **文中批注与批注栏双向联动**：点击文中的批注标记会定位并高亮批注栏里对应条目，点击条目则滚动到文中该批注并闪示；拖选文字仍优先走批注流程，不受影响。

### 自动化与知识

- **后台自动整理**：有界并行（默认同时 2 篇，可配 1–4），按小批次读取全文并逐批落盘；完成后会生成一份结构化的**精读笔记草稿**（一句话概括、研究问题、核心主张附页码、方法与数据、主要结果、局限与疑点、证据等级、待核实与未覆盖），状态为待核对。
- **实时伴学（可选，默认关闭）**：保存或修改带评论的批注后，用本篇论文当前的 DSH 模型按连续阅读方式回应，答复写回 PDF 源批注下；同类问题在 1.8 秒内合并，未完成的任务重启可恢复，不确定的生成不会默默重试。
- **知识工作流**：数据结构化编码为可审阅草稿，并新增只读的「结构检查」，列出无支撑主张、孤立节点、未被引用的证据等问题，只报告不自动修改。
- **构建引用库**：一键写出 `references.bib` 与身份审计（引用键冲突、DOI 重复、缺失字段、受管 PDF 核对），缺 DOI 的条目区分「有页面链接可补全／只能手工」；可选按 DOI 逐字段核验题名、年份、期刊与第一作者，冲突会同时保留目录值与登记值，只比较、不回写。
- **可选元数据兜底**：可接自部署的 Zotero translation-server（仅回环地址）作为补充供应层，主路径取不到时重试，候选仍须通过精确 DOI／题名核对；该服务不随插件打包或启动，插件只发送标识符与公开链接，不发送 PDF 正文、批注或草稿。

### 范围没有变化的部分

- 仍无全库扫描、无后台 OCR、无向量／全文检索；扫描件与图像不计入结论。
- AI 生成内容一律标记待审阅，不编造作者、日期或 DOI。
- 容量验证仍是约 2,000 条记录 / 1,000 个小型合成 PDF；未验证真实大库、WPS 保存往返与提供商输出质量。
- 原创代码 MIT；默认 PyMuPDF、citeproc 运行时涉及 AGPL，CSL 资源为 CC BY-SA，可选的 Zotero translation-server 为 AGPL-3.0（由使用方单独运行）。

### 验证

当前通过 405 项 JavaScript 与 193 项 Python 测试，以及真实 Chromium 浏览器流程和原生 DSH 集成回执；全部使用合成文档，未发起真实提供商请求。范围与复现方式见 [docs/validation.md](https://github.com/Mappedinfo/dsh-paper-library/blob/main/docs/validation.md)。

安装方式与首帖一致（源码注册到目标 profile，重启 DSH 后从右侧面板打开）。欢迎继续反馈导入失败的文件类型、批注兼容性，以及长时间阅读与整库整理时的表现。
