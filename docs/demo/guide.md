# Paper Library 使用手册

DSH 社区插件 · 阅读、整理、写作与演示

面向首次使用 Paper Library 的用户。本手册以插件自身的使用说明为示例材料，不包含私人论文、账号或研究数据。适用版本：2026-11-06 的 main 源码。

## 01 从一份 PDF 开始

Paper Library 把文献管理、PDF 批注、DSH 对话、画板、LaTeX 写作与 Slides 放在同一个工作环境。文件保存在运行 DSH 的主机上，模型功能沿用宿主配置。

1. 启动 DSH，从开始页或右侧面板打开「文献库」。
2. 点击「导入文献」，选择 PDF；也可导入 DOI、公开链接、JSON、RIS 或 BibTeX。
3. 打开条目，检查标题、作者、日期和 DOI。缺失资料保留待核对，不由系统编造。
4. 用搜索和阅读项目组织资料；需要引用时复制 APA 7 或导出 BibLaTeX。

这份 PDF 本身就可以作为练习：导入后，在下一页选一句说明，留下自己的问题。使用说明属于工具文档，不要把它登记为真实学术论文。

## 02 把问题留在原文旁

阅读器支持连续翻页、缩放和单页／双页阅读。选中文字后可添加高亮、下划线、删除线和评论；便笺、区域批注与手写用于补充想法。

1. 选中「批注随管理副本 PDF 导出」这句话，添加一条高亮。
2. 写下评论：「导出文件后，换一个阅读器还能看到吗？」
3. 保存后，从批注卡片直接「问 DSH」，或把几条批注和临时选文一起带入论文对话。
4. 回答与源批注关联，标明 AI 来源。仍需对照原文判断回答是否准确。

批注随管理副本 PDF 导出；导入原件保持不变。实时伴学是可选项，打开后会对带评论的批注自动回应，并使用模型额度。扫描页尚无全文 OCR。

## 03 用项目和画板组织关系

阅读项目按主题组织多篇文献，一篇文献可以属于多个项目。移出项目只解除关联，不删除文献。

画板用于表达概念、证据和阅读路径。新增文本、便签、形状或连线，把文献节点放进图中，双击节点可返回阅读器。支持可读 JSON、Mermaid 子集与 draw.io 互通。

练习：创建「插件上手」画板，用三个节点表示「读说明」「写问题」「试导出」，连接成一条路径。把本手册关联到画板，便于随时回查。

知识图谱和精读笔记可以从明确选中的资料生成。AI 结果是待审阅草稿，核对出处后再采用。数据集条目可登记版本与文件，并有限预览本地表格；这些能力不会自动扫描私人全库。

## 04 在 LaTeX 工作台继续写作

点击「LaTeX」，登记已有项目或创建新项目。源码与编译 PDF 并排显示，章节导航帮助定位文件。编译依赖本机的 latexmk 与相应 TeX 引擎。

1. 编辑并保存 .tex，再编译并检查错误信息。
2. 在 PDF 中定位源码，或在源码和 PDF 中留下自审批注。
3. 搜索 PDF 正文，或按章节范围搜索已保存的 LaTeX 源码。
4. 向 DSH 提问或请求修改提案；检查替换内容后接受，才写入文件。

保存使用版本核对，另一窗口改动后会提示冲突。遇到失败，先保留当前草稿，再重新读取和比较；旧 PDF 不应当作本次编译成功的结果。

## 05 在 Slides 中制作并导出

点击「Slides」，新建项目，选择模板或导入 PlainDeck ZIP。可以编辑文字、图片、表格和摘要卡片，调整主题与布局；「制作指导」帮助明确听众、目的、时长和核心主张。

停止编辑后自动保存，也可使用保存按钮或 Cmd/Ctrl-S。关闭或切换项目之前确认已保存。导出的 PlainDeck ZIP 可重新导入编辑；PPTX 导入目前不支持。

- PPTX：文字、形状、图片、线条和表格保留为可编辑对象。入场动画和镜头缩放写入原生时间轴，需要进入放映查看。
- PDF：适合阅读、打印和批注，是静态输出，不包含播放动画。
- HTML：便于离线浏览和翻页；不要把静态页面等同于 PPTX 动画验收。
- ZIP：保留 PlainDeck 的项目源码与资源，适合继续编辑或交给 AI 处理。

六种入场包括淡入、四个方向的渐入和缩放。动画按 30 fps 换算。已有两页合成稿在 PowerPoint 16.113.3 中确认淡入与镜头缩放正常；WPS 尚未完成实机验收。

## 06 让 DSH 导出已保存的演示

可在对话中这样要求：

> 找到名为「Paper Library 使用说明」的 Slides 项目，导出为 PowerPoint，返回文件位置和导出提示。

AI 可用 library_slides_list 查找项目，调用 library_slides_export_pptx，并传入项目 id。可附 expected_revision，以确保导出的是指定已保存版本。成功结果包含文件路径、页数、修订和 warnings。

网页中的导出可以包含当前草稿；AI 工具与 CLI 使用已保存项目。每个项目的 exports/presentation.pptx 是导出副本，再次导出会替换它。需要保留某次版本时，把副本另存到自己的交付目录。

本套演示的 PlainDeck 源码、ZIP 和 PPTX 来自同一份说明内容。你可以导入 ZIP、修改一句话、保存并再次导出，以此检查整个制作流程。

## 07 选择适合自己的工作台配色

在「设置 → 界面配色」中选择「墨绿铜金」「深海蓝灰」或「跟随 DSH」。配色保存在主机，Paper Library 与 DSH 的设置入口共用；明暗模式和字号继续随宿主。

墨绿铜金使用温暖的浅色纸面与墨绿操作色；深海蓝灰使用清亮白底与海蓝操作色。两套主题都以功能色帮助定位：阅读用墨绿，知识与画板用紫色，写作用海蓝，Slides 用铜金。

颜色同时配有文字标签与选中状态。错误、警告和保存结果继续表达状态；PDF 页面、正文图像和已选择的批注颜色不随界面主题改色。LaTeX 的专用外观设置继续由其工作台管理。

## 08 安装、数据与功能边界

当前功能以仓库 main 源码为准；npm 发布版本与源码更新分别进行。安装需要 Node 22.19 或 24 及以上受支持版本、Python 3.11+、uv 和已构建的 DSH checkout。按 README 执行依赖安装、构建与 install-harness 脚本，明确指定目标 DSH home 和 profile。

资料保存在主机；调用 AI 时，相应原文、批注或稿件会发送给已配置的模型服务。PDF 处理按需运行，没有常驻向量模型，也不会在后台自动解析现有全库。模型账号不可用时，本地阅读、编辑与导出仍可单独使用。
