# 画板中的论文流程

入口为画板工具栏「论文流程」。组件采用用户提供的通用 paperFlow：单图展示与临时编辑、两份文档并排／合并比较、严格或逻辑对应、人工对应、阶段／分组、布局、路由和 JSON／SVG 导出。数学 SVG 与布局依赖均在本地打包，只有打开流程视图才加载浏览器组件，不访问原项目接口、论文来源链接或模型。

## 文档与保存

输入可以是 schemaVersion:1 的 paper-flow-document 或 paper-flow-workspace，解析后统一为工作区；含文档与流程、左右选择、视图、比较配置和独立编辑草稿。示例见 [教学 JSON](../examples/paper-flow-teaching.json)。校验检查端口引用、类型、DAG、显式分组、比较和草稿几何；格式通过不证明论文中的科学主张。

每张画板对应一份 board-flow:<boardId> 主机状态记录。它不进入旧 board: 节点结构、可读源文件或 board-ref 对话快照，不用删除字段或降格端口来适配自由画板。原节点画板和关联可以继续使用。删除父画板不清除附属工作区，但普通接口拒绝访问已删除父板；恢复应由用户从备份或保留的记录处理。

- board_flow_get {id} 返回 {id,workspace,revision}；首次 workspace 为 null、revision 为 0。
- board_flow_save {id,workspace,expected_revision} 返回同结构；使用原状态存储的原子替换、锁与哈希修订保护。父板存在检查与工作区写入是两条记录，不声称它们构成同一个事务。
- 浏览器通用 state_* 不能直接访问 board-flow: 前缀；调用不触发 PDF worker 或模型。

输入和规范化后的 UTF-8 工作区最多 192 KiB；最多 10 份文档、20 个流程，单图 100 节点／200 边，全区 400 节点／800 边。共享校验还限制递归深度、文字与草稿总量，在解析和布局前拒绝过量输入；文件在读取全文前先检查大小。超过限制不会覆盖已保存版本。

## 编辑、切换与恢复

变更合并为串行保存。写入期间继续编辑会保留新版本；只有响应明确确认捕获的工作区才清除待保存状态。网络失败、内容不一致和 CAS 冲突保留草稿；重试与重新读取分开，后者在有草稿时要求明确放弃。JSON 备份可保存当前内容，包括尚未成功写入的工作区。

切换、关闭、新建和删除当前画板先处理流程；失败则停留。流程激活时，DSH 隐藏标签保留其 iframe，普通隐藏 PDF 仍可回收。关闭或刷新时，未保存／冲突／保存中的状态请求浏览器提醒；宿主强制移除 iframe、浏览器崩溃或明确忽略提醒不在保证范围。离开操作先回滚尚未松手的临时拖动，再保存已完成的编辑。

独立静态站将工作区保存在同一浏览器的本地导出容器中，不连接 DSH 私有存储。全部 JSON 备份保留旧 boards 数组并增加 flow_workspaces；导入重复画板时同步改写附属关系。可用时使用 Web Locks，并在异步校验后复读版本；不把浏览器存储描述为跨设备或服务器事务。

本次未注入可选 PDF 导出服务，界面提供工作区 JSON 与 SVG。流程视图没有自动替换自由画板的节点或对话引用；两份流程的人工对应也不自动成为科学等价。

组件来源、复制边界与原依赖许可见 [vendor 说明](../vendor/paper-flow/README.md) 和 [第三方清单](../THIRD_PARTY.md)。本地修改包括导入预算、动态 SVG 属性转义及宿主持久化；未复制原项目适配器、研究数据或报告。
