# 画板中的论文流程

入口为画板工具栏「论文流程」。组件采用用户提供的通用 paperFlow：单图展示与临时编辑、两份文档并排／合并比较、严格或逻辑对应、人工对应、阶段／分组、布局、路由和 JSON／SVG 导出。数学 SVG 与布局依赖均在本地打包，只有打开流程视图才加载浏览器组件，不访问原项目接口、论文来源链接或模型。

图例、比较报告和人工对应与排除位于顶部按钮，按需打开可拖动、缩放尺寸的非阻断浮窗；Escape 或关闭按钮退出并返回入口焦点，画布仍可点选与编辑。人工对应窗口关闭重开保留填写内容，切换比较对象后关闭失效窗口。画布使用工具栏下方的剩余高度，长摘要单独滚动；单图、并排与合并视图共用该布局。屏幕图与导出 SVG 均不再包含底部图例，查看含义请打开「图例」。

「导入 JSON」使用统一按钮并显示文件名、读取状态和错误，也可直接拖入整个流程面板；一次一个 `.json` 文件，读取前检查 192 KiB 上限。拖入失败保留当前图，晚到结果不会覆盖切换后的工作区。「完整细节」开关显示当前状态，旁边问号说明：关闭时只按输入明确的概览分组合并展示，打开时展示分项；没有声明分组时可能没有变化，不修改原始声明或比较依据。浅绿色「保存工作区」下载 JSON 备份，主机保存状态仍在上方单独显示。

## 文档与保存

输入可以是 schemaVersion:1 的 paper-flow-document 或 paper-flow-workspace，解析后统一为工作区；含文档与流程、左右选择、视图、比较配置和独立编辑草稿。示例见 [教学 JSON](../examples/paper-flow-teaching.json)。校验检查端口引用、类型、DAG、显式分组、比较和草稿几何；格式通过不证明论文中的科学主张。

每张画板对应一份 board-flow:<boardId> 主机状态记录。它不进入旧 board: 节点结构或可读源文件；引用时另建固定快照，既有引用不会重写，不用删除字段或降格端口来适配自由画板。原节点画板和关联可以继续使用。删除父画板不清除附属工作区，但普通接口拒绝访问已删除父板；恢复应由用户从备份或保留的记录处理。

- board_flow_get {id} 返回 {id,workspace,revision}；首次 workspace 为 null、revision 为 0。
- board_flow_save {id,workspace,expected_revision} 返回同结构；使用原状态存储的原子替换、锁与哈希修订保护。父板存在检查与工作区写入是两条记录，不声称它们构成同一个事务。
- 浏览器通用 state_* 不能直接访问 board-flow: 前缀；调用不触发 PDF worker 或模型。

输入和规范化后的 UTF-8 工作区最多 192 KiB；最多 10 份文档、20 个流程，单图 100 节点／200 边，全区 400 节点／800 边。共享校验还限制递归深度、文字与草稿总量，在解析和布局前拒绝过量输入；文件在读取全文前先检查大小。超过限制不会覆盖已保存版本。

## 编辑、切换与恢复

变更合并为串行保存。写入期间继续编辑会保留新版本；只有响应明确确认捕获的工作区才清除待保存状态。网络失败、内容不一致和 CAS 冲突保留草稿；重试与重新读取分开，后者在有草稿时要求明确放弃。JSON 备份可保存当前内容，包括尚未成功写入的工作区。

切换、关闭、新建和删除当前画板先处理流程；失败则停留。流程激活时，DSH 隐藏标签保留其 iframe，普通隐藏 PDF 仍可回收。关闭或刷新时，未保存／冲突／保存中的状态请求浏览器提醒；宿主强制移除 iframe、浏览器崩溃或明确忽略提醒不在保证范围。离开操作先回滚尚未松手的临时拖动，再保存已完成的编辑。

独立静态站将工作区保存在同一浏览器的本地导出容器中，不连接 DSH 私有存储。全部 JSON 备份保留旧 boards 数组并增加 flow_workspaces、board_annotations；导入重复画板时同步改写附属关系。可用时使用 Web Locks，并在异步校验后复读版本；不把浏览器存储描述为跨设备或服务器事务。

未注入可选 PDF 导出服务，界面提供工作区 JSON 与 SVG。流程视图不会替换自由画板的节点或旧对话引用；两份流程的人工对应也不自动成为科学等价。

## 对话引用与画板批注

在 DSH 中，顶部「流程放入 DSH」引用 A 侧原流程。点击节点后，可将该节点与沿明确有向关系可达的全部上游、下游加入主输入框；概览分组按明确成员展开，合并图分别提供 A、B 原流程入口，不猜测显示别名。不会自动带上旁支，不把方向当作因果；读者新增关系与输入关系分别标记。先保存当前稿并核对修订，再生成不可变材料快照；引用正文最多 24,000 字符，完整、部分与省略数量明确列出，发送时还受既有总引用预算约束。仅准备输入框草稿，不自动发送或调用模型；独立静态站没有 DSH 引用入口。

「流程批注」「批注此节点」及画板工具栏「画板批注」复用阅读侧栏的「批注」，支持整图、节点或明确节点组的文字记录、编辑、删除与定位；返回阅读后仍显示原来的 PDF 批注。进入侧栏时退出遮挡它的全屏／专注状态。目标移除后保留创建时的摘录并标记失效，不误定位到同名节点。每条正文最多 4,000 字符、摘录 2,000 字符，每板最多 200 条、总记录 240 KiB；保存在独立 board-annotations:<boardId> 状态，采用修订保护，不写 PDF 或源图。未保存文字阻止切板、新建、关闭或删除当前板；选择其他节点不会抢走焦点或改掉正在编辑的批注目标，保存失败保留文字。静态站复用同一批注格式与存储逻辑，以非阻断窗口展示，导出全部 JSON 时包含批注。

## 比较依据与可选展示提示

核心不按论文 ID、领域、角色名称或端口名称推断时空范围、训练关系或结果可比性。严格比较使用已声明的操作签名；逻辑比较要求双方明确提供 `logical.key` 和 `logical.function`，默认比较其余已声明的逻辑字段（端口映射另用于关系比较）。缺失、空值或 `unknown` 等未确认值不能作为一致的证据。同名阶段 ID 只有在完整定义一致时才可自动对齐；冲突定义在合并图分别保留，未声明的阶段定义不会借用另一侧名称。显式阶段映射中的未映射阶段分别保留，未分阶段节点继续标为未分阶段。

需要按部分逻辑字段对齐时，双方可声明相同的 `logical.compare_fields` 路径列表，例如 `["key", "function", "constraints.material"]`；路径相对于 `logical`，顺序不影响含义，`key` 和 `function` 始终必需。所选字段须在两侧明确已知且一致；其余字段不参与匹配，但已有差异仍保留并显示。比较报告提供 `comparedFields`、`notCompared` 与 `declaredDifferences`；字段匹配仅描述输入声明，不证明事实正确、整体等价或性能可排名。未配对不表示另一侧不存在相同步骤，也不推断上游声明变化会影响下游结果。合并的节点与关系保留另一侧原声明和差异。

默认树状布局先完成基线路由，再在有限几何候选中联合尝试节点横移、两端连接点和中间走廊，只接受全图交叉、贴线不增加且总成本下降的方案，不要求逐节点声明提示。候选保持原来的同层次序、泳道与比较分栏；`node.layout.optimizePosition: false` 可禁止该节点的额外横移。已有手工草稿沿用保守布局规则，再恢复手动坐标、固定端点和路线；拖拽预览也保留固定连接点。复杂图仍可能存在交叉，不能把局部改进描述为全局无交叉保证。

显式视觉偏好独立于比较结论：`edge.layout.preferStraight: true` 优先拉直该边，原有 `node.layout.optimizePosition: true` 提示继续兼容；`edge.hover_key` 指定跨图联动提示，只有两侧明确声明相同已知值时生效。未提供悬停键时可按已声明的关系类型联动；这只是查看提示。关系样式沿用显式 `trunk_relation`／`trunk_control`，核心不根据训练、参数或选择等名称赋予特殊含义。旧文档无需补提示即可导入，提示只影响展示，不补写科学字段。

领域适配留在调用侧。授权的本地样例可继续由原适配器生成通用文档，并显式补充展示提示；这类研究输入、适配副本与回执存放在 Git 忽略目录，不进入源码、npm 包或静态站。
