# 画板中的论文流程

入口为画板工具栏「论文流程」。组件采用用户提供的通用 paperFlow：单图展示与临时编辑、两份文档并排／合并比较、严格或逻辑对应、人工对应、阶段／分组、布局、路由和 JSON／SVG 导出。数学 SVG 与布局依赖均在本地打包，只有打开流程视图才加载浏览器组件，不访问原项目接口、论文来源链接或模型。

文献工具栏的「比较」打开右侧栏，可选择流程 A 和比较对象 B、导入 JSON 或下载工作区。再次点击「比较」即可收起。切到「代码与数据」会保留 A/B 选择和草稿。布局、层级、细节、缩放和 SVG 导出位于画布上方。画板全屏时，侧栏开关和「返回 DSH」位于画板内。

图例、比较报告和人工对应与排除可从流程工具栏打开，各自使用可拖动、调整尺寸的浮窗。Escape 或关闭按钮退出并返回入口焦点，画布仍可点选与编辑。人工对应窗口关闭重开保留填写内容，切换比较对象后关闭失效窗口。画布使用工具栏下方的剩余高度，长摘要单独滚动；单图、并排与合并视图共用该布局。屏幕图与导出 SVG 均不再包含底部图例，查看含义请打开「图例」。

在「比较」内点击「导入 JSON」，或把文件直接拖到画布或比较侧栏。导入时会显示文件名、读取状态和错误。一次一个 `.json` 文件，读取前检查 192 KiB 上限。拖入失败保留当前图，晚到结果不会覆盖切换后的工作区。「完整细节」开关显示当前状态，旁边问号说明：关闭时只按输入明确的概览分组合并展示，打开时展示分项；没有声明分组时可能没有变化，不修改原始声明或比较依据。浅绿色「保存工作区」下载 JSON 备份，主机保存状态仍在上方单独显示。

## 用 EqTrace 从实验源码制图

可以让 agent 完成适配，例如「用 `paper-library-flow` 把模型和训练入口生成为画板 JSON。根据数据加载器补输入轴注解，保留无法确定的调用。」它会从源码生成流程，核对画板能否导入、能否渲染，再交付文件。在「比较 → 导入 JSON」查看结果。[技能与调用说明](../skills/paper-library-flow/SKILL.md)

进入画板的「论文流程」，点击顶部的「编码器–解码器示例」。教学图直接显示在主画布，点击「返回原流程」可恢复原来的选区、比较和草稿。空画板可以点击「将示例加入空画板」保存一份。自己的文档可以从「比较」导入 JSON，在「代码与数据」的「已有插图」中可再次打开。文档同时含有网络图和训练图时，顶部提供「网络结构」与「训练流程」切换。有阶段总览时可切换「源码阶段总览」和「全部节点」。在单图工作区，「编辑流程」打开流程编辑器，「查看论文插图」切回插图。[编码器–解码器示例](../examples/eqtrace-attention.json) · [残差模型与训练双图](../examples/eqtrace-training.json)

**读网络图。** 在编码器–解码器示例中，悬停解码器的交叉注意力节点。查询来自目标序列，形状为 `B × T × 32`。键和值来自编码器，形状为 `B × S × 32`。其中 `B` 是批大小，`S` 和 `T` 分别是源、目标序列长度。输出保留查询的长度，输入投影权重为 `96 × 32`。源码显式设置了 `need_weights=False`，因此 `attn_weights` 一行显示「未返回（None）」。[示例源码](https://github.com/Mappedinfo/eqtrace/blob/main/examples/paper_flow/attention.py)

**在节点浮窗核对实际大小。** 打开「代码与数据」，在「关联实际输入」里为 `source`、`target` 等模型输入选择同一批次的数值数组（单个输入对应一个 `.npy`）。例如，若源输入文件的形状为 `4 × 12`，编码器 LayerNorm 的浮窗会列出该文件名，在切片轴标注 `B = 4`、行轴标注 `S = 12`，并把该层输出推为 `4 × 12 × 32`。只关联源输入时，目标长度 `T` 仍未指定。两个文件的同名轴冲突时，保留上一次有效关联。文件仅读取本地头部，关闭当前图后可重新关联。

内置演示采用一组标为「示例输入」的尺寸（`B = 2`、`S = 8`、`T = 5`）。导入的流程若已有实测记录，可在图的 `observed_dimensions` 中逐轴提供值和来源，例如 `{"B":{"value":4,"source":"source-batch.npy"}}`。选择本地数据后，整张图采用本次关联的批次；节点中间形状仍由源码推导。

**读训练图。** 残差回归示例把批循环内的清梯度、前向、损失、反向和参数更新按源码顺序连接，保存权重位于循环之后。对带多进程的脚本，图可分别标出启动和等待。总览合并有源码依据的阶段，详细图保留分支、控制条件与出处。某次运行实际经过哪些阶段、是否成功完成，须结合该次运行记录判断。[合成训练入口](https://github.com/Mappedinfo/eqtrace/blob/main/examples/paper_flow/train.py)

每个节点都可用鼠标悬停、Tab 聚焦或轻点查看。浮窗按输入、输出和参数列出已声明或可静态推导的形状，以条格、矩阵或末两轴切片表示不同维数。标量标作 `[]`，可确定的符号维原样保留，证据不足显示「形状未知」，控制或调度节点可显示「不涉及张量」。旧文档仍可查看已有的端口信息。卡片较长时可滚动，Escape 关闭。网格表示维度，不包含运行时张量数值。「下载论文 SVG」导出当前总览或详细图的矢量文字与连线。

**从源码生成。** 本机 PaperLibrary 服务和 DSH 插件支持选择 Python 源码。在文献工具栏打开「代码与数据」，找到「从源码生成」。选训练入口、模型定义或两者，每份最多 256 KiB。训练和模型同文件时可只选训练入口。文件有多个网络时填模型类名，自定义前向方法可填 `Class.method`。宿主把选定文件交给本机 `board_flow_eqtrace`，后者通过隔离启动入口调用随包的 EqTrace 纯规则解析器。所选源码按文本做静态分析，解析结束后清理临时目录，画板保存生成的流程和源码依据。此过程无需导入用户模型、执行训练或调用语言模型。[随包模块与版本](../vendor/eqtrace/README.md)

独立静态站支持导入和浏览生成的 JSON。也可在装有 EqTrace 的机器上从其仓库根目录运行以下命令，再将 `residual-flow.json` 导入画板。使用本机 PaperLibrary 时，可用 `PAPER_LIBRARY_EQTRACE` 显式指定另一份支持 `paper-flow` 命令的 CLI 绝对路径。

```sh
eqtrace paper-flow --root examples/paper_flow --entry train.py --model residual.py \
  --class ResidualRegressor --title "残差回归" --out residual-flow.json
```

## 文档与保存

输入可以是 schemaVersion:1 的 paper-flow-document 或 paper-flow-workspace，解析后统一为工作区；含文档与流程、左右选择、视图、比较配置和独立编辑草稿。示例见 [教学 JSON](../examples/paper-flow-teaching.json)。校验检查端口引用、类型、DAG、显式分组、比较和草稿几何；格式通过不证明论文中的科学主张。

每张画板对应一份 board-flow:<boardId> 主机状态记录。它不进入旧 board: 节点结构或可读源文件；引用时另建固定快照，既有引用不会重写，不用删除字段或降格端口来适配自由画板。原节点画板和关联可以继续使用。删除父画板不清除附属工作区，但普通接口拒绝访问已删除父板；恢复应由用户从备份或保留的记录处理。

- board_flow_get {id} 返回 {id,workspace,revision}；首次 workspace 为 null、revision 为 0。
- board_flow_save {id,workspace,expected_revision} 返回同结构；使用原状态存储的原子替换、锁与哈希修订保护。父板存在检查与工作区写入是两条记录，不声称它们构成同一个事务。
- 浏览器通用 state_* 不能直接访问 board-flow: 前缀；调用不触发 PDF worker 或模型。

输入和规范化后的 UTF-8 工作区最多 192 KiB；最多 10 份文档、20 个流程，单图 100 节点／200 边，全区 400 节点／800 边。共享校验还限制递归深度、文字与草稿总量，在解析和布局前拒绝过量输入；文件在读取全文前先检查大小。超过限制不会覆盖已保存版本。

## 编辑、切换与恢复

变更合并为串行保存。写入期间继续编辑会保留新版本；只有响应明确确认捕获的工作区才清除待保存状态。网络失败、内容不一致和 CAS 冲突保留草稿；重试与重新读取分开，后者在有草稿时要求明确放弃。JSON 备份可保存当前内容，包括尚未成功写入的工作区。

切换、关闭、新建和删除当前画板先处理流程；失败则停留。流程激活时，DSH 隐藏标签保留其 iframe，普通隐藏 PDF 仍可回收。关闭或刷新时，未保存／冲突／保存中的状态请求浏览器提醒；宿主强制移除 iframe、浏览器崩溃或明确忽略提醒不在保证范围。离开操作先回滚尚未松手的临时拖动，再保存已完成的编辑。

独立静态站将工作区保存在同一浏览器的本地导出容器中，不连接 DSH 私有存储。全部 JSON 备份保留旧 boards 数组并增加 flow_workspaces、board_annotations；导入重复画板时同步改写附属关系。可用时使用 Web Locks，并在异步校验后复读版本；不把浏览器存储描述为跨设备或服务器事务。

未注入可选 PDF 导出服务，界面提供工作区 JSON 与 SVG。流程视图不会替换自由画板的节点或旧对话引用；两份流程的人工对应也不自动成为科学等价。

## 对话引用与画板批注

在 DSH 中，「比较」侧栏里的「流程放入 DSH」引用 A 侧原流程。点击节点后，可将该节点与沿明确有向关系可达的全部上游、下游加入主输入框；概览分组按明确成员展开，合并图分别提供 A、B 原流程入口，不猜测显示别名。不会自动带上旁支，不把方向当作因果；读者新增关系与输入关系分别标记。先保存当前稿并核对修订，再生成不可变材料快照；引用正文最多 24,000 字符，完整、部分与省略数量明确列出，发送时还受既有总引用预算约束。仅准备输入框草稿，不自动发送或调用模型；独立静态站没有 DSH 引用入口。

在文献工具栏点击「侧边栏」可收起或展开左侧或右侧的资料库和批注。收起侧栏时，正在输入的批注和滚动位置会保留。

「流程批注」「批注此节点」及画板工具栏「画板批注」复用阅读侧栏的「批注」，支持整图、节点或明确节点组的文字记录、编辑、删除与定位；返回阅读后仍显示原来的 PDF 批注。进入侧栏时退出遮挡它的全屏／专注状态。目标移除后保留创建时的摘录并标记失效，不误定位到同名节点。每条正文最多 4,000 字符、摘录 2,000 字符，每板最多 200 条、总记录 240 KiB；保存在独立 board-annotations:<boardId> 状态，采用修订保护，不写 PDF 或源图。未保存文字阻止切板、新建、关闭或删除当前板；选择其他节点不会抢走焦点或改掉正在编辑的批注目标，保存失败保留文字。静态站复用同一批注格式与存储逻辑，以非阻断窗口展示，导出全部 JSON 时包含批注。

## 比较依据与可选展示提示

核心不按论文 ID、领域、角色名称或端口名称推断时空范围、训练关系或结果可比性。严格比较使用已声明的操作签名；逻辑比较要求双方明确提供 `logical.key` 和 `logical.function`，默认比较其余已声明的逻辑字段（端口映射另用于关系比较）。缺失、空值或 `unknown` 等未确认值不能作为一致的证据。同名阶段 ID 只有在完整定义一致时才可自动对齐；冲突定义在合并图分别保留，未声明的阶段定义不会借用另一侧名称。显式阶段映射中的未映射阶段分别保留，未分阶段节点继续标为未分阶段。

需要按部分逻辑字段对齐时，双方可声明相同的 `logical.compare_fields` 路径列表，例如 `["key", "function", "constraints.material"]`；路径相对于 `logical`，顺序不影响含义，`key` 和 `function` 始终必需。所选字段须在两侧明确已知且一致；其余字段不参与匹配，但已有差异仍保留并显示。比较报告提供 `comparedFields`、`notCompared` 与 `declaredDifferences`；字段匹配仅描述输入声明，不证明事实正确、整体等价或性能可排名。未配对不表示另一侧不存在相同步骤，也不推断上游声明变化会影响下游结果。合并的节点与关系保留另一侧原声明和差异。

默认树状布局先完成基线路由，再在有限几何候选中联合尝试节点横移、两端连接点和中间走廊，只接受全图交叉、贴线不增加且总成本下降的方案，不要求逐节点声明提示。候选保持原来的同层次序、泳道与比较分栏；`node.layout.optimizePosition: false` 可禁止该节点的额外横移。已有手工草稿沿用保守布局规则，再恢复手动坐标、固定端点和路线；拖拽预览也保留固定连接点。复杂图仍可能存在交叉，不能把局部改进描述为全局无交叉保证。

显式视觉偏好独立于比较结论：`edge.layout.preferStraight: true` 优先拉直该边，原有 `node.layout.optimizePosition: true` 提示继续兼容；`edge.hover_key` 指定跨图联动提示，只有两侧明确声明相同已知值时生效。未提供悬停键时可按已声明的关系类型联动；这只是查看提示。关系样式沿用显式 `trunk_relation`／`trunk_control`，核心不根据训练、参数或选择等名称赋予特殊含义。旧文档无需补提示即可导入，提示只影响展示，不补写科学字段。

领域适配留在调用侧。授权的本地样例可继续由原适配器生成通用文档，并显式补充展示提示；这类研究输入、适配副本与回执存放在 Git 忽略目录，不进入源码、npm 包或静态站。
