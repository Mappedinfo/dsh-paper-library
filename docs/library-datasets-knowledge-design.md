# 文献、数据集与知识工作流

2026-09-15。已实施：独立条目与论文关联 → 有限数据预览 → 两个项目技能的知识工作流。验证入口见[验证记录](validation.md)，调用契约见 [API](api.md)。本实现独立于 Zotero；没有迁移用户的现有资料或调用真实模型服务进行测试。

## 对象与引用

库内有独立的 Paper、Dataset、DatasetRelease 和 Asset。论文保留原来的 ID、PDF、批注、引用快照和 DSH 会话身份。数据集没有 PDF 或介绍论文也能登记；版本属于数据集，文件可以绑定具体版本或保留版本未知。

| 对象 | 保存的事实 | 保持的边界 |
|---|---|---|
| 文献 | 论文、报告等 CSL 元数据和管理副本 PDF | 原有 Paper API 和批注持久化兼容 |
| 数据集 | 名称、创建者、发布者、入口、许可、范围、别名及引用键 | 不强制 DOI 或规范引用论文 |
| 数据版本 | 版本号、自己的 DOI、日期及引用信息 | 不把文件名或下载日期当作官方版本 |
| 文件登记 | 选择的主机路径或 URL、格式、版本绑定及文件指纹 | 登记不读取文件内容，不下载远程数据包 |

引用元数据以插件目录为权威来源。Zotero 是可选的导入来源，保留可用外部 ID、引用键与版本，不建立运行时依赖，也不回写 Zotero。

数据系列、版本和介绍论文分别拥有身份。跨论文／数据集／版本检查 DOI 与引用键冲突；引用键修改后保留别名。不会根据同名自动合并。JSON、RIS 和 BibLaTeX 导入中的数据集进入独立目录；已经存在于 Paper 表中的历史条目不自动迁移。

CSL JSON 的统一引用导出保留 `resource_kind`、`external_id` 和版本父对象映射，可以重新导入引用目录。BibLaTeX `@dataset` 保留版本和引用字段，但不承诺恢复系列与版本的内部映射。缺少作者、年份或发布者时返回警示，不补造信息。

## 论文与数据集的关联

一条关系保存一个论文、一个数据集或明确版本、关系类型、角色、使用范围和多条独立证据。

| 关系 | 含义 |
|---|---|
| 提及 mentions | 文中出现数据集 |
| 引用 cites | 引用了数据记录 |
| 实际使用 uses | 论文实际使用，另记训练、测试、案例等角色 |
| 发布 produces | 论文报告创建或发布数据 |
| 介绍 describes | 数据说明论文或报告 |

证据保存原文、已知页码／章节、来源标识和可用哈希。未知位置留空。关系可在论文和数据集两边查询；数量按不同论文 ID 去重，不把候选关联当作已核对使用。AI 提议始终待审阅；用户核对关系不等于系统证明科学结论成立。

旧论文图中的 dataset 节点保留原身份。`dataset_graph_promote` 提供显式登记或绑定操作并保存映射，不据此推断 uses；同名节点不自动合并。当前图谱节点界面仍沿用原阅读图，提升操作通过 API 使用。

## 界面与使用路径

库列表和扩展表格使用「全部／文献／数据集」过滤。选择论文继续原阅读界面；选择数据集切换到元数据、版本、文件和相关论文，不启动 PDF 或批注路径。返回论文恢复其阅读页码与草稿。阅读中继续只使用一条库／批注共享侧栏。

数据集工具栏提供编辑、添加版本、连接文件、关联论文、APA／BibLaTeX 和知识工作流。版本行可直接引用或打开版本知识。登记程度 L0／L1／L2 用于人工整理，不由下载状态或模型置信度自动升级。

表单草稿保存在主机。另一浏览器已修改数据时，保存返回冲突，显示当前记录和本窗口草稿导出；只有显式核对差异后才允许使用最新修订作为保存基础。

## 有限预览

只在点击预览时读取所选本地文件，先支持 UTF-8 CSV、TSV 和 JSONL。其他格式保留文件登记与不支持提示。

| 预算 | 当前上限 |
|---|---:|
| 返回数据行 | 100 |
| 返回列 | 50 |
| 响应体 | 512 KiB |
| 输入读取 | 4 MiB |
| 单条物理行 | 64 KiB |
| 单字段 | 8192 字符 |
| 解析时间 | 2 秒 |

解析达到预算、遇到异常编码或无效行时，返回有效的部分行和警示；不先加载整个文件再裁剪，也不截断单个单元格冒充完整值。结果始终标为样本，`total_rows` 为 null。样本哈希只覆盖读取部分，不能当作全文件校验值。文件被替换时不能凭相同名字自动重绑定；用户可以重新核对并编辑路径。

Node 顺序调度短时 worker，预览进程有独立超时与取消。没有后台目录扫描、数据内容索引、常驻向量模型或大文件自动下载。1 GiB 稀疏合成 CSV 的短时 worker 实测见[内存记录](validation/dataset-preview-memory.json)；该测量排除了浏览器和 DSH 主机，不能用于宣称整个应用的内存上限。

## 知识工作流

工作流为：明确选择对象 → 保存来源 → 勾选材料 → 生成待审阅草稿 → 核对 → 保存 Markdown 或使用已审核图。

来源类型包括已保存批注、官方摘录、用户文字、元数据摘录和已有资料说明。批注按精确版本从 PDF 读取；其他摘录只保存用户明确提供的文字，不凭 URL 自动抓取全文。固定来源保留正文、评论、对象身份、位置、证据级别和哈希。之后可以显式检查单条批注是否已修改或删除，旧来源不会被重写。元数据和 source-note 不自动升级为全文证据。

每次最多选择 40 条来源、合计 24,000 字符。模型由条目的 DSH 原生会话决定；数据版本继承所属数据集的会话模型。来源选择不启动模型，明确生成才使用额度。调用通过 DSH 服务，可由连接同一认证服务的浏览器访问；独立预览服务未配置 DSH 代理时不具备生成能力。

生成请求、固定输入与输出检查点保存在主机；相同请求 ID 重放不会重复调用模型。曾中断或失败的请求需要用户明确发起新的生成。模型草稿统一 needs-review，高置信度也不能自动接受；模型工具不能审核自己的草稿或覆盖正文。

结构化知识区分 Evidence、Figure、Formula、Observation、Claim、Gap、Method、Dataset、Metric、Task 等类型。Evidence 引用选定来源的精确摘录，Observation 指向来源节点；Evidence／Observation 对 Claim／Gap 的认识关系用 Assertion，对象之间的结构关系用 Edge。关系端点、类型与来源通过有界校验。用户接受图草稿后可以查询和导出；接受笔记草稿后仍需编辑并保存正文。

`paper-library-knowledge` 是 Research Knowledge OS 契约的项目适配，负责来源与 typed graph；`paper-library-notes` 适配 knowledge-note 的可读笔记工作流，解释定义、例子、机制、用途、比较和限制。两个技能采用独立名称和真实插件工具，沿用当前 DSH 模型。没有复制原技能的 CLI、私有专家库、Wiki、APA Bridge 或质量记录；来源版本与许可边界见[适配清单](upstream-manifest.md)。

## 持久化与导出

| 内容 | 权威位置 |
|---|---|
| 文献、数据集、版本、文件登记、论文关联、固定来源与结构化草稿 | 配置的资料库 SQLite |
| PDF 批注 | 管理副本 PDF 的标准批注对象 |
| 知识笔记正文 | `knowledge/notes/<id>-r<revision>.md` |
| 编辑草稿、来源选择、生成请求检查点 | DSH-home 下以资料库路径区分的私有状态目录 |
| 论文／数据集会话及模型选择 | DSH 原生会话文件 |

笔记跨 SQLite 与 Markdown 写入使用持久化 intent、原子发布和恢复流程；旧正文修订保留。成功回执后才显示已保存；未送达主机的文字不能因页面关闭而获得持久化保证。浏览器 localStorage、IndexedDB 和缓存不承担资料存储。

引用导出包含文献、数据集和版本的引用元数据，最多 24 MiB；分页间核对目录修订，避免混合不同版本。知识 JSON 导出只包含明确选定范围的已审核图、笔记、所引用的固定来源和对象身份资料。它不是包括所有未审草稿、文件、关联和会话的整库备份，也没有整包恢复入口。

RKOS v3 导出生成区分角色的引用文件与知识 sidecar、ID 映射和损失报告。它是兼容子集，不能承担无损备份。原版无法把 bibliographic `@dataset` 作为原生来源，因此数据集的 Evidence 来源链保存在知识 JSON，v3 中明确报告不支持，不伪造一篇 Paper 承接。缺少上下文层级、必要字段或置信度时报告映射缺失，不编造字段通过校验。

运行时只用项目自身的有界校验与映射器。合成导出额外通过明确选定的原 RKOS parser/build/lint 函数验证；没有执行它的默认 CLI 发现流程，见[兼容验证](validation/rkos-subset.json)。

## 验证范围和后续边界

自动化覆盖独立身份、双向关系、版本引用与往返导入、CAS、归档、文件替换、输入／输出预算、固定来源、AI 待审阅、笔记崩溃恢复和导出损失。浏览器覆盖条目创建、版本、有限预览、APA、知识审核、Markdown、换浏览器恢复、批注变化检查和返回 PDF。原生 DSH 测试使用无密钥确定性模型，验证认证、数据集／版本模型继承、所选材料、图谱输出与重启幂等。旧阅读共享侧栏回归保留。

尚未实现：包含全部文件与会话的整库备份／恢复、数据文件托管复制或浏览器上传、Parquet／GIS／影像专用预览、全库知识抽取、独立预览页的 DSH 连接代理。新功能的整体桌面内存、真实研究数据和真实模型输出质量没有本轮实测。
