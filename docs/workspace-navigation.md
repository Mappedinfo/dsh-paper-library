# 文献、画板与 LaTeX 写作导航

文献库的阅读项目筛选上方提供三个入口：文献、画板、LaTeX 写作。文献保留已有的检索、阅读项目、资料类型、表格与分页；画板和写作项目各自使用名称检索与分页目录，统一行高、按钮、关联说明及翻页控件。进入写作项目后，编译版本显示在该项目下面，不再与文献目录混排。

选择条目后，面包屑记录当前路径；「关联子内容」按类别列出已有联系，点击后打开对应原条目。文献、画板和写作项目可以互相显示为关联子项。这是浏览关系，不改变文件归属，不复制内容、不创建物理父子目录，也不自动新增关联。路径最多保留最近8项，返回已访问条目会收回其后路径；不会递归展开关系环。

同一份导航随当前界面显示；LaTeX 写作时移到工作台顶部，关闭后回到内容目录。切换先保护当前笔迹、对话草稿、画板／流程／批注及写作改动。明确指定的画板或写作项目找不到时显示失败，不回退打开其他条目；分页窗口外的明确ID可单独核对后打开。版本查询只使用当前写作项目ID，清空时同时清理旧分页和迟到响应。

## 关联依据

- 画板的 `links.papers` 和文献节点中的 `paper.id` 是明确的文献关联，双向展示；文献节点保留其关系类型说明。
- 文献的阅读项目成员关系、画板的 `links.projects`、写作项目的 `reading_project_id` 可提供共同阅读项目联系；每项注明「通过阅读项目」，不冒充直接绑定。
- 不按题名、文件夹名、路径或引用键猜测联系；不扫描 LaTeX 源码或引用内容建立关系。
- 已失效的直接文献关联保留原标识并禁止打开。元数据读取失败、读取范围不完整和确实为空分别显示，未知数量使用下限提示。

## 只读接口

`workspace_catalog {kind:'board'|'latex',query?,offset?,limit?}` 返回统一目录；`workspace_related {kind:'paper'|'board'|'latex',id,group_kind?,offset?,limit?}` 返回当前条目的分组关联子项。每页最多20项，目标为 `{kind,id,title,relation?,via?,missing?}`；分组包含 `total`、`known_total`、`offset`、`has_more`、`truncated`，并提供读取提示。扫描不完整时 `total:null`，`known_total` 只是已知数量。

画板关系发现使用当前最多50张的原目录窗口；写作关系使用最多200个活动项目的元数据窗口。通过阅读项目展开时，单次最多10个项目、每项目40篇文献；最多4个并发元数据请求。当前页面直接绑定的文献才逐项核对资料，不后台全库扫描。窗口不足或部分读取失败会明确提示，不能把未显示当作不存在。目录分页与关系发现窗口是不同边界。

接口只投影已有元数据和绑定，不写资料库，不解析 PDF、不编译、不生成版本或调用模型；现有的画板与写作编辑接口继续负责改动和冲突处理。

## 检查

合成测试覆盖三类目录、双向关系、部分读取与失效项、面包屑与分页、迟到响应、导航保存保护、精确目标与版本项目隔离。入口为 `tests-js/workspace-*.test.mjs`，并复用 `board-panel`、`latex-panel`、`latex-version-http`、`library-layout` 与 `workbench` 的相关检查。默认完成代码检查，界面由用户手动检查。
