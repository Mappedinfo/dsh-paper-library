# 公式识别与资源开销

本次修复将参考文献区段、网址与数学候选分开处理。不是把 References 所在页及后续全部删除：同页标题之前的公式保留，参考文献区段跨页延续，遇到 Appendix／附录等标题恢复公式提取。采用独立标题和普通双栏顺序；不把正文中提到 references 当作区段边界。没有标准标题或复杂混合版式仍可能误判。

## 当前算法

1. 复用已有 PDF 文本行、字体、基线与坐标。独立参考文献标题切换区段状态，按页持久化；不额外扫描前文或全文。跳页扫描而前文区段未知时暂缓未知区域的公式，顺序扫描时补检，不能将这类页标为完整覆盖。
2. 排除 URL、DOI、`Available from`、`?ref=` 等网址参数以及作者年份式引用。旧规则遇到短网址的等号会误报。
3. 结合数学算符／字体、独立编号与短行识别公式候选；支持 `(A.2)` 附录编号，合并同基线片段，并补入同文字块中相邻的短分式／上下标片段，避免裁剪只剩公式中段。相邻独立公式不合并。
4. 公式裁剪为原始依据。文本层乱码不自动改造成 LaTeX；邻近定义只呈现原文，不猜符号含义。文本解析不等于数学语义识别。

索引升级为 `document-elements-v3`，旧候选失效。保存页面草稿后刷新，打开公式侧栏继续扫描；仍按原资源档位逐页运行。仅重建当前篇派生索引，不修改 PDF 原件或批注，不扫描全库。缓存命中后的页面不会反复提取。

## 合成性能对照

复跑：`uv run python scripts/benchmark-formula-detection.py --output docs/validation/formula-detection-benchmark.json`。

基线固定在 `3e79a5d`。两版分别在独立进程中处理同一份临时生成的 42 页 PDF，各遍历三次；包含正文、带网址的参考文献及附录，预期 28 条公式。计时涵盖每页结构提取（文字、几何和表格检查），不含进程启动、SQLite 持久化和预览渲染。内存是整个测试 Python 进程的峰值 RSS，不是插件／浏览器总占用，也不是硬上限。未读取 SPOK 或其他私人文献。

| 指标 | 旧版 | 修复版 |
| --- | ---: | ---: |
| 保留的预期公式 | 28 / 28 | 28 / 28 |
| 误报 | 57 | 0 |
| 单页中位耗时 | 9.017 ms | 9.021 ms |
| 单页 P95 | 9.451 ms | 9.290 ms |
| 进程峰值 RSS | 63.84 MiB | 60.31 MiB |

这个样本中没有观察到实质性的速度或内存开销增加；RSS 的小差异不能证明节省了相应内存。此样本刻意覆盖报错模式，不能推导真实文献总体精确率／召回率。原始结果见 [JSON](validation/formula-detection-benchmark.json)。63 项合成回归检查覆盖网址排除、跨页 References、附录恢复、跳页补检、普通双栏、分式边界、旧缓存迁移及既有图表／资源检查。

## 是否需要更重的识别模型

| 路径 | 适用情况 | 性能与限制 |
| --- | --- | --- |
| 文本层＋版面规则（当前采用） | 可选文字的 PDF，快速列出可定位候选 | 复用按页解析；不下载模型，不栅格化整页。复杂编码、内联公式和非标准排版仍可能遗漏。 |
| 图像公式检测 | 无文本层，或公式由路径／图片构成 | 可采用 PDF-Extract-Kit 的 YOLO 公式检测；增加图像准备、模型权重和推理开销。本次未安装或测量，不承诺本机耗时或 512 MiB 内存目标。 |
| 公式图像转 LaTeX | 需要可编辑公式或修复文本层乱码 | PDF-Extract-Kit 提供 UniMERNet；应当在明确请求时只处理选定公式裁剪，并缓存结果。本次没有接入，生成式结果仍需对照原图。 |

PyMuPDF 官方说明文字 `dict` 提取默认可能携带图像，关闭图像提取可减少时间和空间；当前代码已关闭该标志。[文本提取文档](https://pymupdf.readthedocs.io/en/latest/app1.html)

PDF-Extract-Kit 官方分别列出公式检测 YOLOv8_ft 和公式识别 UniMERNet，并要求下载对应权重；二者解决定位与转写两个不同问题。[官方项目与模型列表](https://github.com/opendatalab/PDF-Extract-Kit#model-overview)

据此，本次采用轻量区段／文本／几何规则修复。对当前可选文字 PDF 没有必要默认增加常驻识别模型；扫描件和精确 LaTeX 可作为后续按需能力单独评价。
