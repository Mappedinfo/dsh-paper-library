# 论文获取与入库

本技能随 Paper Library 插件提供，入库使用插件配置的独立资料库。无需运行 Zotero，也不另建文献目录或模型配置。

## 获取指定论文

- 对 DOI、arXiv ID、PDF 直链或论文页面调用 `library_import`：`{"url":"论文链接或 arXiv ID"}`，DOI 也可用 `{"doi":"10.…/…"}`。
- 对已存在的 PDF 调用 `library_import`：`{"path":"本地 PDF 的路径"}`。相对路径以当前 DSH 会话工作区为基准。
- 只有标题时，先用当前可用的检索工具结合作者、年份定位 DOI 或官方页面；多义标题不要随意取第一个结果。本技能不承诺未安装的 MCP 或浏览器 provider 可用。
- 用户已经指定下载或导入的论文就直接处理；批量按顺序执行，逐篇报告结果。已有管理副本会去重或复用。

导入工具负责公开链接解析、流式下载、PDF 可读性校验、最多前三页的本地资料提取、经题名匹配的 DOI 资料补全，以及管理副本命名。格式是 `作者-年份-标题--稳定标识.pdf`；缺失作者或年份保留明确占位，原件不改动。题名匹配失败、扫描件或识别不完整时使用 `parse.needs_review` 和 warnings 表示待核验，不能编造缺失信息。

## 判断实际结果

1. 检查返回的 `items`、`warnings` 和 `acquisition`。只有 `item.pdf === true` 才有已保存的管理 PDF；`metadata_only` 表示只获得了文献资料，不能说“论文已下载”。
2. 需要核对信息时用 `library_get` 读取条目；`pdf_filename` 是实际管理文件名，`parse` 说明解析来源与待核验状态。用阅读面板或 `library_annotations` 查看已有批注。
3. 没有 PDF 时报告具体原因。可使用用户已有、合法获得的 PDF 继续导入；不能把摘要、网页、登录页或 HTML 错误页当作论文 PDF。
4. 用户要求引用时用 `library_cite` 输出 APA 或 BibLaTeX；不手写 DOI、作者或引用键。用户要求批注反馈时使用 `library_feedback`，默认继承当前 Harness 模型。

## 访问与资源边界

仅使用公开的 HTTP(S) 下载路径。每次请求与重定向校验目标地址，不访问回环、内网、链路本地地址或携带凭据的 URL。不提取浏览器 cookie，不启动后台浏览器，不绕过验证码、登录或付费限制。失败会保留明确状态和来源记录；受限论文需要用户已有的合法文件或另外授权的访问渠道。

文件按流落盘，下载和 PDF 处理按需运行；不启动全库 OCR、向量索引或常驻模型。PDF 当前上限为 250 MiB / 2,000 页；网页和元数据有独立小容量上限。原生 PDF 批注及已有内嵌书目信息随副本保留。
