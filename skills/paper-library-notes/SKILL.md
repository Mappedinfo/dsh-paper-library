# 从来源到可读笔记

这是 Paper Library 的原创方法适配，采用项目 MIT 许可。笔记正文由插件保存在资料库的 Markdown 文件，结构化身份与来源关系由目录管理；不要使用浏览器存储、另建私有目录或直接编辑数据库。继续使用当前 DSH 模型。

对象可以是文献、独立数据集或具体版本。先通过 `library_resources` 定位，再使用 `library_knowledge` 的 `source_list` 和 `source_get` 读取用户明确选择的完整来源；参数为 `operation` 和 JSON 字符串 `input_json`。来源不足时保留未核验内容，不扫描全文库或自行启动额外模型。

对需要形成完整解释的对象，正文按读者理解顺序组织：一句话定义、贯穿的具体例子、内容与机制、发展与现状、同一任务下的替代选择、上下游、适用场景、限制与来源。短登记不强制扩写成长笔记；来源不支持历史或比较时明确说明。数据集应解释记录单位、字段、时空覆盖、版本、获取方法、许可状态及它适合回答的问题。数值、日期与性质须绑定来源；抽样统计不冒充全量数据事实。

原文摘录、来源报告、作者推断和模型解释应可区分。引用来源 ID 并保留现有 citekey，不手写第二份题名、作者、年份或 DOI。对于动态数据，记录实际快照／版本，未知项保持未知。不把下载成功或官方元数据当作数据质量认证。

生成后使用 `library_knowledge` 的 `draft_put` 保存提案，`input_json` 内容为：

```json
{"entity":{"kind":"dataset","id":"用户选择的ID"},"mode":"note","source_ids":["明确选择的来源ID"],"title":"知识页题名","body":"Markdown 正文与来源ID引用","nodes":[],"edges":[],"assertions":[]}
```

使用 `draft_get` 读回检查。所有 AI 笔记先标为待审阅；请用户在界面阅读、修改并保存到知识正文。模型工具没有接受草稿或覆盖正文的权限。已有笔记可通过 `note_list`／`note_get` 读取，再提出新草稿；不把旧正文内容悄悄替换。

对完成的笔记，核对定义可读、例子具体、比较标准一致、每个主张具有实际来源或明确推断标记。图谱校验和标题齐全不能证明读者已经理解。仅当比较确有用途时建立综合笔记，不为每篇相关论文复制一整页数据说明。
